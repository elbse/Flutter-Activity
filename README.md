## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/elbse/flutter_application_1.git
   ```

2. Navigate to the project folder:

   ```bash
   cd flutter_application_1
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
